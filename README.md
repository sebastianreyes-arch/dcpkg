este repo contiene un gestor de paquetes hecho por mi, pensado para descargar unicamente programas cli 


se debe clonar  el repo en la carpeta /usr/ y mover el archivo dc-pkg a la carpeta /usr/bin/ ya con eso deberia poder usar el gestor de paquetes, aun es moy pequeño pero la idea es hacerlo creser de apocos

por el momento solo cuenta con los siguentes comandos
  dc-pkg install <paquete>
  dc-pkg remove <paquete>
  dc-pkg list
